# Executable SoS Runtime and Whole-System Benchmark

**Status:** IMPLEMENTED REFERENCE RUNTIME / INTEGRATION FOUNDATION

The canonical repository now contains an executable reference runtime and black-box benchmark harness.

## Runtime hierarchy

External Human Authority
-> Constitution
-> Governance
-> Authorization
-> SoS coordination
-> Independent ecosystems

## Operational loop

Index
-> Understand
-> Build/Reconstruct
-> Test
-> Evidence
-> Verify/Qualify
-> Governed Adoption
-> Re-index
-> Evolve

The runtime does not replace the independent ecosystems. It provides the executable coordination boundary into which adapters can be connected.

## Dual witnesses

Index Machine records identity, source, timestamps, lineage, construction and capability metadata.

Authorization records authority source, constitutional basis, scope, delegation, expiration, revocation and ratification state.

BI/evidence records establish observations and scoped dispositions.

These dimensions are deliberately independent.

## Benchmark layers

A whole-system Arena evaluation should report separate results for:

1. Runtime correctness.
2. Cross-system integration.
3. Tool/capability use.
4. Reasoning and planning.
5. Engineering/build/reconstruction.
6. Evidence and verification behavior.
7. Governance and authorization compliance.
8. Adversarial resistance.
9. Historical/provenance integrity.
10. Evolution and re-indexing.
11. Human-authority boundary preservation.

A single intelligence score may be reported by the evaluator, but it must not replace the dimensional results.

## Current status

The runtime is executable. This does **not** establish that every ecosystem is connected, production-ready, verified, qualified, or intelligent to any particular degree. Those claims require live evidence.
