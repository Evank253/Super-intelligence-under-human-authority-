# ASI Qualification Evaluation

This directory is the executable evaluation boundary for the canonical
Super Intelligence Under Human Authority repository.

The harness provides frozen task representations, system adapters,
deterministic adjudication where ground truth exists, evidence-state recording,
cryptographic record hashes, aggregate scoring, and a constitutional authority
gate.

A harness smoke test is NOT evidence of AGI, ASI, or superhuman performance.

Actual qualification requires hidden/unseen tasks, preregistered comparators,
domain coverage, adversarial testing, statistical analysis, reproducibility,
independent review, and human ratification.

Until those conditions are met, overall ASI status remains NOT ESTABLISHED.
