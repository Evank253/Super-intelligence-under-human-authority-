# EA-G1 Implementation Contract

- **Generation:** EA-G1 — Evolutionary Architecture Generation 1
- **Status:** Experimental Implementation
- **Specification baseline:** Frozen Conceptual Architecture
- **Historical impact:** NONE

## Contract

1. Implement against the frozen specification without silently changing it.
2. Enforce distinctions through mechanisms, not documentation alone.
3. Preserve historical records and explicit `NOT MEASURED` / `UNRESOLVED` states.
4. Require provenance and evolution traceability.
5. Keep human ratification explicit and separate from qualification.
6. Preserve implementation results separately from historical evidence and the conceptual baseline.
7. Treat failures and limitations as G1 evidence, not as reasons to rewrite the baseline.
