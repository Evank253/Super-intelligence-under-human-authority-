# Architecture Plane — M04

The architecture plane defines systems, components, capabilities, boundaries, dependencies, authority, governance, provenance, integration points, and experimental boundaries.

It does not execute systems, perform integration, or qualify emergent intelligence.

## Evidence rule

DECLARED → IMPLEMENTED → OBSERVED → VERIFIED → QUALIFIED

Declared capability is not observed capability. Implemented capability is not verified capability. Verified capability is not qualified emergence. Qualification does not grant authority.

## Core invariant

A system may declare a capability, the integration layer may expose it, and the experimental layer may test it—but only evidence can establish what the system actually demonstrated.
