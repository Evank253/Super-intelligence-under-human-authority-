# System Architecture

```
HUMAN AUTHORITY
      ↓
CONSTITUTION
      ↓
SAFETY + AUTHORIZATION
      ↓
AI ROUTER / INTERFACE
      ↓
CAPABILITIES / MODELS / AGENTS / TOOLS / DATA
      ↓
RAW OUTPUTS
      ↓
EVIDENCE INTAKE
      ↓
PROVENANCE + INTEGRITY
      ↓
CLAIM REGISTRATION
      ↓
E0–E5 EVIDENCE STATE
      ↓
VERIFICATION
      ↓
QUALIFICATION
      ↓
EXECUTION AUTHORIZATION
      ↓
EXECUTION
      ↓
OBSERVATION / TELEMETRY
      ↓
HUMAN REVIEW
```

KSI-ASI-001 spans the entire architecture and prohibits intelligence components from using capability, confidence, consensus, or execution success to self-elevate evidence or authority.
