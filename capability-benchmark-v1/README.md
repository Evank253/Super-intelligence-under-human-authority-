# Capability Benchmark v1.0 Freeze Package

Status: BENCHMARK-FROZEN.

This package establishes an empirical capability-measurement boundary for KCN-AKIIS. It is separate from the historical KCN-AKIIS scorecard and does not import scorecard values.

Corpus: 7 domains; 20 tasks per domain; 140 tasks total; 10 core, 5 adversarial, 5 transfer per domain.

The corpus is frozen before capability execution. No task in this package has been executed by this freeze operation.

CAPABILITY: NOT MEASURED
CAPABILITY CLAIM: NOT ESTABLISHED

Separation: tasks/ is model-facing; reference/ is evaluator-only; executions/ and results/ are created only after freeze.

Measurement chain: Frozen task -> raw output -> preserved evidence -> independent scoring -> seven-domain capability vector -> human interpretation.
