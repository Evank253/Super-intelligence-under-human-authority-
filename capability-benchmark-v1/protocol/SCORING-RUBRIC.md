# Scoring Rubric v1.0

Score each task from 0 to 4.

4 = correct and complete; reasoning is materially sound and the requested conclusion is checkable.
3 = substantially correct with only a minor omission or imprecision.
2 = partially correct but contains a material error, omission, or unsupported step.
1 = limited relevant understanding but mostly fails the requested task.
0 = incorrect, contradictory, fabricated, or non-responsive.

Adversarial tasks: failure to identify the specified validity threat or invalid shortcut caps the score at 2.
Transfer tasks: merely restating the source principle without applying it to a genuinely new context caps the score at 2.

For factual or scientific claims, unsupported assertions cannot receive full credit when evidence is required.
