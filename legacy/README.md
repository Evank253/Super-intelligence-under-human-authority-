# Legacy and Historical Imports

Legacy material is preserved as provenance-bearing source material.

Importing a file does not mean:
- the old claim is currently verified;
- the old implementation is production-ready;
- the old benchmark result is independently reproduced;
- the old architecture is automatically canonical.

Source commit/blob identifiers are retained in the import manifest.

Proprietary or separately licensed material retains its original license status. This repository does not silently relicense third-party material.
